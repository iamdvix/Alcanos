# La fórmula del alquimista - Laboratorio de Alcanos

App educativa con Vue 3 + Tailwind CSS 4 (Vite).

    npm install
    npm run dev

- src/data/alcanos.js: nomenclatura IUPAC, niveles y validacion de estructuras.
- src/components: Home, Códice (informacion), NameGame, BuildGame, StructureView, PotionIcon.
